# Security Policy

## Scope

Skyjoust is an offline single-player desktop game with no network server, user accounts, telemetry, or authentication. Its GitHub Pages showcase (`docs/`) is a static client-side page using Google `<model-viewer>` for 3D GLB previews and local HTML5 audio playback.

## Reporting a Vulnerability

If you discover a security issue in the repository, build scripts, or showcase page, please report it privately via [GitHub Private Vulnerability Reporting](https://github.com/charles-forsyth/skyjoust/security/advisories/new) rather than opening a public issue.
